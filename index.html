ASSISTANTTurn 1 Response

To build a simple top-down 2D zombie survival game where characters are plain square boxes, you only need Unity's built-in 2D physics components and three short C# scripts.

Step 1: Set Up the Scene

  1. Create a 2D Project in Unity Hub.
  2. Floor: Right-click the Hierarchy → 2D Object → Sprites → Square. Name it Floor, set scale to (20, 20, 1), and give it a dark grey colour in the Sprite Renderer.
  3. Player:
    • Create another Square: 2D Object → Sprites → Square. Name it Player.
    • Set colour to Blue.
    • Add a Rigidbody 2D component. In the Inspector, set Gravity Scale to 0 and check Constraints → Freeze Rotation Z.
    • Add a Box Collider 2D.
    • Set tag to Player (at the top of the Inspector).
  4. Main Camera: Ensure it is positioned at (0, 0, -10) with Projection set to Orthographic.

Step 2: Player Movement and Shooting

Create a C# script named PlayerController.cs and attach it to your Player object.

using UnityEngine;

public class PlayerController : MonoBehaviour
{
    public float moveSpeed = 6f;
    public Rigidbody2D rb;
    public GameObject bulletPrefab;
    public Transform firePoint;

    private Vector2 movement;
    private Vector2 mousePos;

    void Update()
    {
        // 1. Arrow / WASD input
        movement.x = Input.GetAxisRaw("Horizontal");
        movement.y = Input.GetAxisRaw("Vertical");

        // 2. Mouse aiming
        mousePos = Camera.main.ScreenToWorldPoint(Input.mousePosition);

        // 3. Shoot on Left Mouse Click
        if (Input.GetButtonDown("Fire1"))
        {
            Shoot();
        }
    }

    void FixedUpdate()
    {
        // Move physics body
        rb.MovePosition(rb.position + movement.normalized * moveSpeed * Time.fixedDeltaTime);

        // Rotate facing the mouse
        Vector2 lookDir = mousePos - rb.position;
        float angle = Mathf.Atan2(lookDir.y, lookDir.x) * Mathf.Rad2Deg - 90f;
        rb.rotation = angle;
    }

    void Shoot()
    {
        if (bulletPrefab != null)
        {
            Instantiate(bulletPrefab, transform.position, transform.rotation);
        }
    }
}

Step 3: Bullet Setup

  1. Create another 2D Square. Name it Bullet.
  2. Change its scale to (0.2, 0.4, 1) and colour to Yellow.
  3. Add a Rigidbody 2D (set Gravity Scale to 0).
  4. Add a Box Collider 2D and check Is Trigger.
  5. Create a C# script named Bullet.cs, attach it to Bullet, then drag Bullet into your Project Assets folder to turn it into a Prefab. Delete it from the scene hierarchy.
  6. Select Player in the Hierarchy and drag the Bullet prefab into the Bullet Prefab slot of PlayerController.
using UnityEngine;

public class Bullet : MonoBehaviour
{
    public float speed = 15f;
    public Rigidbody2D rb;

    void Start()
    {
        rb.velocity = transform.up * speed;
        Destroy(gameObject, 3f); // Destroy automatically after 3 seconds
    }

    void OnTriggerEnter2D(Collider2D hitInfo)
    {
        if (hitInfo.CompareTag("Zombie"))
        {
            Destroy(hitInfo.gameObject); // Kill zombie
            Destroy(gameObject);        // Destroy bullet
        }
    }
}

Step 4: Zombie Setup

  1. Create another 2D Square. Name it Zombie.
  2. Change its colour to Red or Green.
  3. Add a Rigidbody 2D (set Gravity Scale to 0, check Freeze Rotation Z).
  4. Add a Box Collider 2D.
  5. Add a new Tag named Zombie in Unity and assign it to this object.
  6. Create a script named Zombie.cs and attach it to Zombie:
using UnityEngine;
using UnityEngine.SceneManagement;

public class Zombie : MonoBehaviour
{
    public float speed = 3f;
    private Transform player;

    void Start()
    {
        GameObject p = GameObject.FindGameObjectWithTag("Player");
        if (p != null) player = p.transform;
    }

    void Update()
    {
        if (player != null)
        {
            // Move directly towards player
            transform.position = Vector2.MoveTowards(transform.position, player.position, speed * Time.deltaTime);
        }
    }

    void OnCollisionEnter2D(Collision2D collision)
    {
        if (collision.gameObject.CompareTag("Player"))
        {
            // Reload the current scene if the zombie touches the player
            SceneManager.LoadScene(SceneManager.GetActiveScene().buildIndex);
        }
    }
}
  1. Drag Zombie into your Project Assets folder to turn it into a Prefab, then delete it from the Hierarchy.

Step 5: Zombie Spawner

Create an empty GameObject in your scene hierarchy (Right-click → Create Empty), name it Spawner, and attach this script:

using UnityEngine;

public class EnemySpawner : MonoBehaviour
{
    public GameObject zombiePrefab;
    public float spawnInterval = 2f;
    public float spawnDistance = 10f;

    void Start()
    {
        InvokeRepeating(nameof(SpawnZombie), 1f, spawnInterval);
    }

    void SpawnZombie()
    {
        // Pick a random point on a circle around the centre
        Vector2 randomCircle = Random.insideUnitCircle.normalized * spawnDistance;
        Vector3 spawnPos = new Vector3(randomCircle.x, randomCircle.y, 0);

        Instantiate(zombiePrefab, spawnPos, Quaternion.identity);
    }
}

Drag the Zombie prefab from your Assets into the Zombie Prefab field on the Spawner component.

Quick Checklist Before Hitting Play

  • Tags: Ensure Player has tag Player and Zombie prefab has tag Zombie.
  • Rigidbodies: Ensure all Rigidbody 2D components have Gravity Scale = 0.
  • Colliders: Bullet collider has Is Trigger checked; Player and Zombie have standard colliders.

Here is the streamlined setup using standard C# scripts via Unity’s built-in scripting engine (MonoBehaviour), keeping everything self-contained so you don’t need any external packages or complex asset configurations.

1. Player Script (PlayerMovement.cs)

using UnityEngine;

public class PlayerMovement : MonoBehaviour
{
    public float moveSpeed = 6f;
    public GameObject bulletPrefab;

    private Rigidbody2D rb;
    private Vector2 moveInput;
    private Vector2 mouseWorldPos;

    void Start()
    {
        rb = GetComponent();
    }

    void Update()
    {
        moveInput.x = Input.GetAxisRaw("Horizontal");
        moveInput.y = Input.GetAxisRaw("Vertical");

        if (Camera.main != null)
        {
            mouseWorldPos = Camera.main.ScreenToWorldPoint(Input.mousePosition);
        }

        if (Input.GetMouseButtonDown(0))
        {
            Shoot();
        }
    }

    void FixedUpdate()
    {
        rb.linearVelocity = moveInput.normalized * moveSpeed;

        Vector2 aimDirection = mouseWorldPos - rb.position;
        float targetAngle = Mathf.Atan2(aimDirection.y, aimDirection.x) * Mathf.Rad2Deg - 90f;
        rb.rotation = targetAngle;
    }

    void Shoot()
    {
        if (bulletPrefab != null)
        {
            Instantiate(bulletPrefab, transform.position, transform.rotation);
        }
    }
}

2. Zombie Tracking Script (ZombieMovement.cs)

using UnityEngine;
using UnityEngine.SceneManagement;

public class ZombieMovement : MonoBehaviour
{
    public float moveSpeed = 3f;
    private Transform targetPlayer;
    private Rigidbody2D rb;

    void Start()
    {
        rb = GetComponent();
        GameObject playerObj = GameObject.FindGameObjectWithTag("Player");
        if (playerObj != null) targetPlayer = playerObj.transform;
    }

    void FixedUpdate()
    {
        if (targetPlayer != null)
        {
            Vector2 direction = ((Vector2)targetPlayer.position - rb.position).normalized;
            rb.linearVelocity = direction * moveSpeed;

            float angle = Mathf.Atan2(direction.y, direction.x) * Mathf.Rad2Deg - 90f;
            rb.rotation = angle;
        }
        else
        {
            rb.linearVelocity = Vector2.zero;
        }
    }

    void OnCollisionEnter2D(Collision2D collision)
    {
        if (collision.gameObject.CompareTag("Player"))
        {
            SceneManager.LoadScene(SceneManager.GetActiveScene().buildIndex);
        }
    }
}

3. Bullet Motion & Collision Script (BulletMovement.cs)

using UnityEngine;

public class BulletMovement : MonoBehaviour
{
    public float bulletSpeed = 16f;
    public float lifeTime = 3f;
    private Rigidbody2D rb;

    void Start()
    {
        rb = GetComponent();
        rb.linearVelocity = transform.up * bulletSpeed;
        Destroy(gameObject, lifeTime);
    }

    void OnTriggerEnter2D(Collider2D other)
    {
        if (other.CompareTag("Zombie"))
        {
            Destroy(other.gameObject);
            Destroy(gameObject);
        }
    }
}

ASSISTANTTurn 3 Response

Unity does not have a separate switch or tool called the "Script Engine" that needs to be turned on. The scripting engine (Mono/.NET runtime) runs automatically in the background whenever you press Play in the editor.

If your C# scripts are not executing or your movements are not working, it is almost always due to one of four common setup issues:

  1. The Script Is Not Attached to the GameObject: Drag the script into the Inspector of the active object.
  2. A Compilation Error Is Freezing Execution: Check the bottom bar or Console tab for red errors.
  3. Missing Component Dependencies: Ensure Rigidbody 2D is present if required.
  4. Code Editor Not Linked: Connect Visual Studio / VS Code in Edit → Preferences → External Tools.

In Unity, a Script Machine is a component of Unity Visual Scripting (formerly known as Bolt). It allows you to create game mechanics using visual node graphs instead of writing C# code.

Step 1: Add the Script Machine Component

  1. Click on your Player in Hierarchy.
  2. Click Add Component → search for Script Machine.
  3. Under Source set to Graph, click New and save as PlayerMovementGraph.
  4. Click Edit Graph.

Step 2: Build the Movement Nodes

  • Input: Get Axis Raw ("Horizontal") & Input: Get Axis Raw ("Vertical")
  • Create Vector 2 (Horizontal → X, Vertical → Y)
  • Vector 2: Normalize
  • Vector 2: Multiply by speed (6) and by Time: Get Delta Time
  • Connect flow: On Update → Transform: Translate (Translation)

Yes, your sir used the Transform: Translate (X, Y, Z) node. This method directly takes individual axis values, skipping vector nodes and math calculations entirely.

The 4-Block Setup

Visual Scripting 4-Block Node Graph
[On Update] ════(Green Flow)═════════════════════════════════════════► [Transform: Translate] │ X: (from Horizontal) [Input: Get Axis ("Horizontal")] ────(Value)───────────────────────────► │ Y: 0 │ Z: (from Vertical) [Input: Get Axis ("Vertical")] ────(Value)───────────────────────────► ┘
  1. Update (Green Event node)
  2. Input: Get Axis (Set Axis Name to "Horizontal")
  3. Input: Get Axis (Set Axis Name to "Vertical")
  4. Transform: Translate (X, Y, Z)

Connect green flow from Update to Translate. Connect Horizontal to X, Vertical to Y (for 2D) or Z (for 3D), and leave the unused axis as 0.

USERTurn 6
what about onkey down
ASSISTANTTurn 6 Response

In Unity Visual Scripting, On Key Down (or On Keyboard Input) only fires once at the exact moment a key is pressed down.

Because continuous movement requires holding keys down rather than tapping them repeatedly, you can use On Keyboard Input set to Hold, or use Input: Get Key with your Update block.

Comparison of Key Actions

ActionWhen It FiresBest Used For
DownExactly one frame when pressedShooting bullets, jumping, pausing
HoldEvery frame the key stays pressedWalking, driving, continuous moving
UpExactly one frame when releasedCharging an attack, releasing a brake

USERTurn 8
ok done it but how is the ball suppose to move without get key input
ASSISTANTTurn 8 Response

The Input: Get Axis block does not need a "Get Key" node because Unity already maps your physical keyboard keys to the words "Horizontal" and "Vertical" under the hood.

  • "Horizontal" is mapped to A / Left Arrow (-1) and D / Right Arrow (+1).
  • "Vertical" is mapped to S / Down Arrow (-1) and W / Up Arrow (+1).

When you hold W, "Vertical" automatically outputs 1.0, which gets sent into Translate's Z input to move forward.

how do i impliment a rewind button
ASSISTANTTurn 25 Response

Two ways to implement rewind:

Method 1: Continuous Rewind Script (Hold 'R' to reverse path)

using System.Collections.Generic;
using UnityEngine;

public class TimeRewind : MonoBehaviour
{
    public bool isRewinding = false;
    private List positions = new List();
    private Rigidbody rb;

    void Start() { rb = GetComponent(); }

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.R)) StartRewind();
        if (Input.GetKeyUp(KeyCode.R)) StopRewind();
    }

    void FixedUpdate()
    {
        if (isRewinding) Rewind();
        else Record();
    }

    void Record()
    {
        positions.Insert(0, transform.position);
        if (positions.Count > 250) positions.RemoveAt(positions.Count - 1);
    }

    void Rewind()
    {
        if (positions.Count > 0)
        {
            transform.position = positions[0];
            positions.RemoveAt(0);
        }
        else StopRewind();
    }

    void StartRewind()
    {
        isRewinding = true;
        if (rb != null) rb.isKinematic = true;
    }

    void StopRewind()
    {
        isRewinding = false;
        if (rb != null) rb.isKinematic = false;
    }
}
